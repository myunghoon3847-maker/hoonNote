Creative Note 계정 삭제

계정을 삭제하면 모든 클라우드 메모, 삽입 링크, 카테고리와 체크리스트가 영구 삭제되며 복구할 수 없습니다. 서버에서 본인 확인과 데이터 연결 상태를 점검한 뒤 삭제합니다.

삭제되는 항목
  • Supabase 로그인 계정
  • 클라우드에 저장된 모든 메모, 삽입 링크, 카테고리와 체크리스트
  • 현재 기기의 Creative Note 자동 저장 초안과 이전 메모

메모 분류

내 업무 방식에 맞게 카테고리를 추가하거나 이름을 바꿀 수 있습니다.

중요·보관·미분류는 삭제할 수 없는 기본 카테고리입니다. 다른 카테고리를 삭제해도 메모는 삭제되지 않고 ‘미분류’로 이동합니다.
