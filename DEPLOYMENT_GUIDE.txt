Creative Note v4.7.0-dev1.1 GitHub Pages 404 긴급복구 배포 안내

중요: ZIP 파일 자체를 GitHub에 올리지 마세요.
1) 이 ZIP을 PC에서 압축 해제합니다.
2) 압축을 풀었을 때 바로 보이는 index.html, manifest.json, service-worker.js, css, js, icons, legal, support, 404.html, .nojekyll을 모두 선택합니다.
3) GitHub의 myunghoon3847-maker/solonote 저장소 → Add file → Upload files에서 위 파일과 폴더를 저장소 최상단에 업로드합니다.
4) index.html이 폴더 안이 아니라 저장소 첫 화면에 보여야 합니다.
5) Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save를 확인합니다.
6) Actions 탭의 pages build and deployment가 초록색 체크가 될 때까지 기다립니다.
7) 웹 주소 https://myunghoon3847-maker.github.io/solonote/?v=471 를 먼저 확인합니다.
8) 웹이 열리면 스마트폰에서 Creative Note 앱을 완전히 종료하고 다시 실행합니다.

정상 구조 예시:

├─ index.html

├─ manifest.json
├─ service-worker.js
├─ .nojekyll
