# 훈노트 v4.5.15

훈노트 v4.5.15는 기존 기능과 UI를 유지하면서 오류 처리와 사용자 안내를 개선한 안정화 버전입니다.

## 주요 개선

- 저장·동기화·백업·복원 오류를 화면 하단 안내 카드로 표시
- 네트워크 연결 끊김과 복구 상태 안내
- 오프라인 저장 시 작성 내용을 자동 초안으로 보호
- 로그인 세션 만료 시 재로그인 화면으로 안전하게 전환
- 저장·로그인·백업·복원 버튼의 중복 실행 방지 및 로딩 표시
- Supabase·네트워크·권한·서버 지연 오류를 사용자용 한국어로 변환
- 실패한 저장·새로고침·복원 작업에 다시 시도 동작 제공
- v4.5.13.2의 메인 화면 내부 메모 작성 패널 유지
- v4.5.13.1의 비밀번호 재설정 단일 흐름 수정 유지
