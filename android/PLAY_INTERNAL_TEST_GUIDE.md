# 훈노트 v4.6.0 RC1 Google Play 내부 테스트

## 1. AAB 생성

1. v4.6.0 RC1 웹 파일을 GitHub Pages에 전체 배포합니다.
2. PWABuilder에서 배포 주소를 검사합니다.
3. Android 패키지를 `com.hooncompany.hoonnote`로 생성합니다.
4. `versionName 1.0.0-rc1`, `versionCode 1`, `targetSdk 36`을 확인합니다.
5. AAB를 생성하되 서명키와 비밀번호를 외부에 공유하지 않습니다.

## 2. Play Console 내부 테스트

1. Google Play App Signing을 활성화합니다.
2. AAB를 내부 테스트 트랙에 업로드합니다.
3. 개인정보처리방침과 계정 삭제 안내 URL을 등록합니다.
4. 로그인이 필요한 앱으로 표시하고 심사용 테스트 계정을 제공합니다.
5. 앱 서명 인증서 SHA-256을 복사합니다.
6. 도메인 루트의 `/.well-known/assetlinks.json`에 앱 서명 지문을 반영합니다.
7. 내부 테스트 링크로 설치합니다.

## 3. 실기기 통과 기준

- 첫 실행에 브라우저 주소창이 나타나지 않음
- 회원가입·로그인·비밀번호 재설정 정상
- 메모 작성·수정·삭제·복원 정상
- 카테고리와 할 일 정상
- 앱 종료 후 재실행 시 로그인 유지
- 웹 새 버전 배포 후 업데이트 안내가 나타남
- 오프라인 재실행 시 앱 껍데기와 안내 화면이 표시됨
- 계정 삭제가 정상 완료됨
- 뒤로가기: 내부 패널 → 메뉴 → 앱 종료 순서가 자연스러움

## 4. RC 중단 조건

- 다른 사용자 데이터 노출
- 메모 저장 후 유실
- 비밀번호 재설정 반복
- 주소창이 계속 표시되는 TWA 검증 실패
- 설치 후 흰 화면 또는 무한 로딩
- 계정 삭제 실패
